# 🎬 PreCut AI — 프리미어의 액기스 + AI 자동 컷 편집

**촬영한 영상을 넣으면 AI가 지루한 부분을 잘라내고, 결과를 Premiere Pro 2025로 바로 가져가서 다듬을 수 있는 프로그램입니다.**

프리미어에서 가장 오래 걸리는 일 — 무음 잘라내기, 쓸 만한 장면 고르기, 자막 받아쓰기 — 를 AI가 대신하고,
프리미어의 액기스(컷 타임라인, 시퀀스, 캡션)는 **XML/EDL/SRT 파일**로 그대로 넘겨줍니다.
마지막 손맛은 프리미어에서, 노가다는 AI가.

```
원본 영상 ──▶ PreCut AI ──▶ ① 완성본.mp4        (그대로 업로드 가능)
                          ├▶ ② 프리미어.xml     (프리미어에서 열어 이어서 편집)
                          ├▶ ③ 자막 SRT 2종     (원본 기준 / 편집본 기준)
                          └▶ ④ 챕터.txt         (유튜브 설명란용 타임스탬프)
```

## 무엇을 해주나요?

| 기능 | 설명 |
|---|---|
| ✂️ **무음 자동 컷** | 말 사이의 침묵, 버벅이는 공백을 찾아 싹둑. 잘리는 느낌이 없게 앞뒤 여유를 남깁니다 |
| 🎞️ **장면 감지** | 화면이 바뀌는 지점을 찾아 컷 단위로 정리 |
| ⭐ **하이라이트 선정** | 소리 크기·장면 정보로 점수를 매겨 "1분 하이라이트", "30초 쇼츠"를 자동으로 |
| 🗣️ **AI 자막** | 음성을 받아써서 SRT 자막 생성 (Whisper) — 편집 후 시간에 맞춘 자막도 함께 |
| 🤖 **말로 시키기** | "1분 30초 하이라이트로 만들고 자막 넣어줘" 같은 한국어 지시문 해석 (Claude) |
| 🧩 **프리미어 내보내기** | 컷이 다 들어간 시퀀스를 FCP7 XML + EDL로 — 프리미어에서 열면 타임라인이 그대로 |

모든 처리는 **내 컴퓨터 안에서만** 이루어집니다. 영상이 어디로 업로드되지 않아요.

## 3분 안에 시작하기

### 준비물 (한 번만)

1. **Python 3.9 이상** — <https://www.python.org/downloads/>
   (윈도우 설치 시 **"Add python.exe to PATH"** 체크 필수!)
2. **ffmpeg** (무료 영상 엔진)
   - 윈도우: 명령 프롬프트에서 `winget install ffmpeg`
   - 맥: 터미널에서 `brew install ffmpeg`

### 실행

- **윈도우**: `시작-윈도우.bat` 더블클릭
- **맥**: `시작-맥.command` 더블클릭 (처음엔 우클릭 → 열기)
- 또는 터미널에서:

```bash
cd precut-ai
python -m precut web
```

브라우저가 자동으로 열립니다. **영상을 끌어다 놓고 → 편집 방식 고르고 → 🚀 버튼**. 끝!

> 환경이 잘 잡혔는지 궁금하면: `python -m precut doctor`

## 웹 화면 사용법

1. **영상 올리기** — 촬영 원본을 드래그&드롭 (MP4/MOV/MKV 등)
2. **편집 방식 선택**
   - `✂️ 무음만 싹둑` — 길이는 유지하고 침묵만 제거 (강의/브이로그용)
   - `⭐ 1분 하이라이트` / `📱 30초 쇼츠` — 제일 재미있는 부분만
   - 텍스트 칸에 **말로 시켜도** 됩니다: *"2분으로 요약하고 자막도 넣어줘"*
3. **🚀 AI 편집 시작** — 진행 상황이 실시간으로 표시됩니다
4. **결과** — 타임라인에서 어디가 잘렸는지 확인하고, 파일 다운로드 & 미리보기

## 프리미어 프로로 가져가기 (핵심!)

완성본을 그대로 써도 되지만, 진짜 실력 발휘는 프리미어에서:

1. Premiere Pro 2025 실행 → **파일 > 가져오기** (Ctrl+I / Cmd+I)
2. 결과 폴더의 **`프리미어.xml`** 선택
3. 프로젝트 패널에 시퀀스가 생깁니다 — 더블클릭하면 **AI가 자른 컷이 전부 타임라인에!**
4. 자막은 **`자막_편집본.srt`** 를 가져와서 캡션 트랙으로 (새 캡션 트랙 만들기)
5. 컷 경계 다듬고, 색보정·BGM·타이틀 올리고 내보내기

자세한 그림 설명: [`docs/프리미어-연동-가이드.md`](docs/프리미어-연동-가이드.md)

## 명령줄로 쓰기 (선택)

```bash
# 통째로 자동 편집 (무음컷 + 렌더 + 프리미어 파일)
python -m precut auto "촬영본.mp4"

# 말로 시키기
python -m precut auto "촬영본.mp4" -p "1분 하이라이트로 만들고 자막 넣어줘"

# 60초 하이라이트만, 렌더링 없이 프리미어 파일만 빠르게
python -m precut auto "촬영본.mp4" --target 60 --no-render

# 자르기 전에 분석만 해보기
python -m precut analyze "촬영본.mp4"

# 자막만 뽑기
python -m precut subtitles "촬영본.mp4" --language ko
```

## 선택 기능 켜기

### 🗣️ AI 자막 (Whisper)

```bash
pip install faster-whisper
```

첫 실행 때 음성 인식 모델을 자동으로 내려받습니다(수백 MB). 속도/정확도는
`--whisper-model tiny|base|small|medium|large-v3` 로 조절 (기본 `small`).

### 🤖 Claude로 지시문 해석 (더 똑똑하게)

API 키가 **없어도** 지시문은 규칙 기반으로 해석됩니다. Claude를 연결하면 애매한 표현도 잘 알아듣습니다:

```bash
pip install anthropic
# 윈도우 (새 창부터 적용)
setx ANTHROPIC_API_KEY "발급받은-키"
# 맥/리눅스 (~/.zshrc 등에 추가)
export ANTHROPIC_API_KEY="발급받은-키"
```

키 발급: <https://console.anthropic.com> (사용한 만큼만 과금).
안전상 요청이 거절되면 자동으로 대체 모델이 이어받도록 서버측 폴백이 기본으로 켜져 있습니다.
모델을 바꾸고 싶으면 `PRECUT_CLAUDE_MODEL` 환경변수로 지정하세요.

## 자주 묻는 질문

**Q. 너무 많이/적게 잘려요.**
웹 화면의 *세부 조정*에서 무음 기준을 조절하세요. 덜 잘리게: −45dB 쪽으로, 더 잘리게: −25dB 쪽으로.
"이만큼 조용해야 컷"을 1초 이상으로 올리면 말 사이 숨 고르기는 살아남습니다.

**Q. 프리미어에서 XML을 열면 미디어가 오프라인이래요.**
원본 영상 파일을 옮기거나 지우면 그렇습니다. 클립에서 우클릭 → **미디어 연결**로 원본 위치를 다시 지정해 주세요.

**Q. 렌더링이 느려요.**
`--no-render`로 프리미어 파일만 만들면 몇 초면 끝납니다. 최종 출력은 프리미어에서 하면 되니까요.

**Q. 영상이 인터넷으로 나가나요?**
아니요. 편집·렌더링·자막 전부 로컬에서 처리합니다. 유일한 예외는 (선택 기능인) Claude 지시문 해석 —
이때도 **지시문 텍스트와 영상 길이 같은 숫자 정보만** 전송되고 영상 자체는 절대 나가지 않습니다.

## 개발자용

```bash
cd precut-ai
python -m unittest discover -s tests -v   # 전체 테스트
pip install -e ".[all]"                    # 개발 설치(선택 기능 포함)
```

구조: `precut/` 아래 — `silence`(무음) · `scenes`(장면) · `highlights`(하이라이트) ·
`subtitles`(자막) · `assistant`(Claude/휴리스틱) · `premiere`(XML/EDL) · `render`(ffmpeg 렌더) ·
`pipeline`(오케스트레이션) · `server`+`static`(웹 UI) · `cli`.

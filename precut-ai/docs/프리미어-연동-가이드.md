# Premiere Pro 2025 연동 가이드

PreCut AI가 만든 결과물을 프리미어로 가져가서 마무리하는 방법입니다.

## 결과 폴더에 뭐가 들어있나

| 파일 | 용도 |
|---|---|
| `완성본.mp4` | AI가 자른 그대로의 최종 영상. 바로 업로드해도 됨 |
| `프리미어.xml` | **가장 중요.** 컷이 전부 들어간 시퀀스 (FCP7 XML 형식) |
| `프리미어.edl` | 같은 컷 목록의 EDL 버전 (XML이 안 될 때 예비용) |
| `자막_원본.srt` | **원본 영상** 시간 기준 자막 → XML 시퀀스에서 쓸 때 |
| `자막_편집본.srt` | **완성본.mp4** 시간 기준 자막 → 완성본에 얹을 때 |
| `챕터.txt` | 유튜브 설명란에 붙여넣는 타임스탬프 |
| `plan.json` | 편집 계획 원본 (다시 내보내기용) |

## 방법 1 — XML로 시퀀스째 가져오기 (권장)

AI가 자른 컷을 프리미어 타임라인에서 그대로 이어서 편집하는 방법입니다.

1. Premiere Pro 실행, 프로젝트 열기(또는 새 프로젝트)
2. **파일 > 가져오기** (윈도우 `Ctrl+I`, 맥 `Cmd+I`)
3. 결과 폴더의 **`프리미어.xml`** 선택
4. 프로젝트 패널에 시퀀스(예: `내영상 - PreCut`)가 생김 → **더블클릭**
5. 타임라인에 AI가 자른 클립들이 순서대로 놓여 있습니다
   - 각 클립은 **원본 영상 파일을 참조**합니다 (복사본이 아님 = 화질 손실 0)
   - 컷 경계를 살짝 다듬고 싶으면 리플 편집 도구(`B`)로 끌면 됩니다
6. 이후는 평소 하던 대로: 전환, 색보정(Lumetri), BGM, 타이틀…

> **미디어 오프라인(빨간 화면)이 뜨면**: 원본 영상 위치가 바뀐 것.
> 클립 우클릭 → **미디어 연결(Link Media)** → 원본 파일 다시 지정.

> **시퀀스 설정이 애매하면**: 시퀀스를 우클릭 → 시퀀스 설정에서 프레임 크기/프레임 속도가
> 원본과 같은지 확인하세요. PreCut이 원본 fps에 맞춰 만들어 줍니다.

## 방법 2 — 완성본.mp4만 가볍게 쓰기

빨리 올리는 게 목표라면 `완성본.mp4`를 그냥 쓰거나,
프리미어에 가져와서 위에 자막·타이틀만 얹으면 됩니다.
이때 자막은 **`자막_편집본.srt`** 를 쓰세요 (완성본 시간에 맞춰져 있음).

## 자막(SRT) 올리는 법

1. **파일 > 가져오기**로 SRT 선택 (`자막_원본.srt` 또는 `자막_편집본.srt`)
2. 프로젝트 패널에서 자막 항목을 타임라인 위로 드래그
3. "새 캡션 트랙"으로 올리면 캡션 트랙이 생깁니다
4. **창 > 필수 그래픽** 또는 캡션 패널에서 글꼴·크기·위치 스타일링
5. 내보낼 때 "캡션 굽기(Burn-in)" 또는 별도 자막 파일로 선택 가능

- XML 시퀀스(방법 1)에서 작업 중이면 → `자막_원본.srt` (원본 시간 기준이라 컷과 자동으로 맞음)
- `완성본.mp4` 위에 얹는 중이면 → `자막_편집본.srt`

## EDL은 언제 쓰나

아주 오래된 버전이나 다른 편집 프로그램(다빈치 리졸브 등)과 주고받을 때 씁니다.
프리미어에서는 **파일 > 가져오기**로 `프리미어.edl`을 선택하면 됩니다.
EDL은 규격상 트랙 1개, 파일명 참조라서 XML보다 정보가 적습니다. 웬만하면 XML을 쓰세요.

## 챕터.txt 활용

유튜브 스튜디오 → 동영상 설명란에 그대로 붙여넣으면
시청자에게 구간 바로가기(챕터)가 생깁니다. 첫 줄이 `00:00`으로 시작해야 하는 규칙도 맞춰져 있습니다.

## 추천 작업 흐름

```
촬영 → PreCut AI (무음컷/하이라이트/자막 자동)
     → 프리미어.xml 가져오기
     → 컷 미세조정 · 색보정 · BGM · 타이틀   ← 사람의 손맛
     → 내보내기
```

노가다(무음 찾아 자르기, 받아쓰기)는 AI에게, 감각이 필요한 일은 프리미어에서.
이게 PreCut AI의 사용법입니다.

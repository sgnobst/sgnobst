# 🎙️ Voice Camera — 말하면 편집되는 카메라

브라우저에서 카메라를 켜고 **말로 명령하면 실시간으로 화면이 편집**되는 웹 앱입니다.
서버·빌드 없이 `index.html` 하나로 동작합니다.

## 실행

- GitHub Pages: `https://sgnobst.github.io/sgnobst/voice-camera/` (저장소 설정에서 Pages를 `main` 브랜치로 켜야 합니다)
- 로컬: `npx serve voice-camera` 또는 아무 정적 서버로 열기 (카메라·마이크는 `https` 또는 `localhost`에서만 허용됩니다)

## 사용법

1. 🎤 버튼을 눌러 마이크를 켭니다 (Chrome / Edge / Safari 권장. 미지원 브라우저는 텍스트 입력 사용).
2. 말합니다: `더 밝게`, `흑백으로`, `빈티지 필터`, `2배 줌`, `따뜻하게 하고 비네팅 추가`, `3초 뒤에 찍어` …
3. 📷 또는 `사진 찍어` / `김치` 라고 말하면 편집된 상태 그대로 JPG로 저장됩니다.

## 명령어

| 말하기 | 효과 |
|---|---|
| 더 밝게 / 어둡게 / 밝기 내려 | 밝기 |
| 대비 올려 / 내려 | 대비 |
| 채도 올려 / 색감 연하게 | 채도 |
| 흑백으로 / 컬러로 | 흑백 전환·복원 |
| 빈티지 · 필름 · 시네마 · 몽환 · 비비드 · 소프트 | 프리셋 필터 |
| 따뜻하게 / 차갑게 | 색온도 |
| 세피아, 페이드, 그레인, 비네팅 | 필름 감성 효과 |
| 블러 / 선명하게 | 흐림 및 해제 |
| 색조 90, 반전 | 색상 회전, 네거티브 |
| 확대 / 축소 / 2배 줌 | 줌 (최대 5배) |
| 좌우반전, 회전, 그리드 | 구도 |
| 카메라 전환 / 후면 카메라 | 전·후면 전환 |
| 사진 찍어 / 치즈 / 김치 / 3초 뒤에 찍어 | 촬영, 타이머 |
| 초기화 / 원래대로 | 모든 효과 제거 |

`조금`, `많이`, `확` 으로 강도를 조절하고, `하고`, `그리고` 로 여러 명령을 이어 말할 수 있습니다.

## 기술

- 카메라: `getUserMedia` → `<canvas>` 실시간 렌더링 (CSS filter + 오버레이 합성)
- 음성: Web Speech API (`ko-KR`, 연속 인식)
- 명령 해석: 정규식 기반 한국어/영어 키워드 매칭, 절 단위 다중 명령 지원
